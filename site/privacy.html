개인정보와 이용 안내

스텔라이브 비공식 개인 정주행 도구입니다. 영상과 공개 정보는 YouTube가 제공합니다. 영상 다운로드, 광고 차단, 접근 제한 우회 기능은 없습니다.

영상별 재생 위치, 완료 여부, 수동 분류는 현재 사이트 경로에 구분하여 브라우저 localStorage에 저장합니다. 운영자 서버나 GitHub로 전송하지 않습니다. 다른 기기와 공유하려면 직접 백업 파일을 옮기세요. 홈 화면 앱과 일반 브라우저의 저장 공간이 다를 수 있습니다.

기록 삭제는 설정 → 고급 관리의 ‘이 사이트의 기록 삭제’를 사용하세요. 이 작업은 이 도구의 로컬 기록만 지우며 YouTube에 저장된 데이터에는 영향을 주지 않습니다.

YouTube 플레이어를 재생하면 YouTube/Google과 통신하며 해당 서비스의 개인정보 처리방침이 적용됩니다. GitHub Pages 접속 기록 처리에는 GitHub 정책이 적용됩니다. 분석 도구는 추가하지 않았습니다. 공개 채널·영상 metadata는 YouTube Data API로 수집하며 정기 갱신합니다. 수동 분류·완료 표시는 YouTube가 제공한 데이터가 아닙니다.

브라우저 자동재생, 지역·연령·로그인·퍼가기 제한 때문에 일부 영상은 원본 YouTube에서 열어야 합니다. 원본에서 시청한 위치는 이 도구로 자동 복사되지 않습니다.
