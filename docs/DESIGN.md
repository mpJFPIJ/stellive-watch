# 모바일 스텔라이브 정주행 설계

사용자가 지정한 GitHub Pages + Actions 구조를 구현한다. 기존 로컬 프로그램의 채널 설정, KST 활동 기간, 공개시각 정렬과 수동 판정을 이전한다. 원본과 비밀 설정 파일은 수정하거나 배포하지 않는다.

Python 표준 라이브러리 수집기는 uploads 전체 페이지를 탐색한다. 채널별 스캔을 체크포인트로 저장하고, 완주한 스캔만 기존 목록을 교체한다. 실패한 요청은 기존 목록을 삭제하지 않는다. 상태는 Actions artifact에 1일 보관한다. 복원 불가 시 전체 재수집한다. API 메타데이터는 Git 이력에 커밋하지 않는다.

정적 빌드는 공개시각/영상 ID 순서로 500개씩 JSON을 분할한다. manifest와 ID 조회 파일로 필요한 조각만 불러온다. 브라우저는 영상 ID별 위치·완료·수동 판정을 저장하며 JSON 백업/복원을 제공한다. 기록에는 제목·공개시각을 넣지 않는다. API 데이터는 29일 경과 시 수집·빌드·열람에서 만료 처리한다.

기존 channels.json은 2026-10-20 원본에서 상속하며 이번 작업에서 전체 채널과 활동일의 진위를 새로 검증한 것은 아니다. 미확인 항목을 표시한다. API 실제 조회는 ID 존재 확인이며 공식 소속 인증은 아니다.

배포는 요청한 저장소와 명시적 권한이 확인된 때만 한다. 이 작업의 기본 결과는 업로드 가능한 완성 ZIP과 설치 안내다. 단일 세션에서 구현·테스트·검토를 수행한다.
