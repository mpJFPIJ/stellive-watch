# 설치·배포 완료

모바일 시청 주소: https://mpjfpij.github.io/stellive-watch/

저장소: https://github.com/mpJFPIJ/stellive-watch

## 확인한 결과

- 사용자 요청에 따라 mpJFPIJ 계정에 공개 저장소를 생성하고 GitHub Pages를 활성화했습니다.
- 기존 YouTube API 키는 YOUTUBE_API_KEY라는 Repository Actions Secret에 등록했습니다. 공개 소스와 웹사이트에는 키를 넣지 않았습니다.
- 최초 실행과 후속 실행 모두 성공했습니다. 후속 실행에서는 이전 수집 체크포인트 복원을 확인했습니다.
- 각 실행에서 26개 채널·영상 9,959개·API 456회 요청·수집 오류 0을 확인했습니다.
- 한국시각 03:23, 09:23, 15:23, 21:23에 예약 갱신합니다. PC는 켜 두지 않아도 됩니다.
- 실제 공개 사이트에서 모바일 화면 너비 390px, 50개 목록, 원본 링크, 새로고침 후 시청 완료 유지, 페이지 오류 0을 확인했습니다.
- 실제 YouTube 플레이어에서도 영상 재생 시작을 확인했습니다. headless Chromium에서 readyState=4, paused=false, error=null이었습니다. 실제 휴대폰 모든 환경·모든 영상 재생을 보장하는 것은 아닙니다.

성공한 후속 실행: https://github.com/mpJFPIJ/stellive-watch/actions/runs/39442849700

## 이용 방법

휴대폰 Safari/Chrome에서 위 주소를 열고 ‘가장 오래된 미시청’을 누르세요. 재생이 막히면 플레이어의 재생 버튼을 직접 누르거나 YouTube 원본 링크를 이용하세요. 시청 기록은 사용한 브라우저에 저장되므로 기기를 바꾸기 전에 ‘기록 백업’을 사용하세요.

GitHub 예약은 60일 비활동 시 비활성화될 수 있습니다. 월 1회 Actions 실행 상태와 사이트 갱신 시각을 확인하세요. 기존 검증결과 문서의 ‘배포하지 않음’은 ZIP 최초 제작 당시 상태이며, 이 문서가 이후의 배포 확인 결과입니다.
