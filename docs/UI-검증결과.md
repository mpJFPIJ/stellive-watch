# UI 개편 검증 · 2026-10-21

- Python 17개 테스트, JavaScript 데이터 로직 7개 테스트 통과.
- 실제 수집 9,959개 영상으로 홈·영상·기록·설정, 320/390/430/1024px 가로 넘침, 50개 목록 교체, 채널/연도/분류 필터, 완료 기록 지속, 다크 모드 지속, JSON 백업·복원, Escape 닫기·이어보기 도크, 연결 실패 후 재시도 검증 통과.
- 모의 YouTube 전송 경계 테스트: 37초 재개, 153 오류 원본 링크, 자동재생 차단, 이전 플레이어 지연 이벤트, 다른 탭의 완료 취소·기록 삭제, 지연된 다음 요청 취소, 닫힌 화면의 늦은 준비 이벤트가 재생하지 않음을 확인.
- 기록 테스트: 45개 기록 페이지, 중간 503 실패 후 중복 없는 재시도, 다른 탭의 재생 위치 갱신에도 펼친 40행 유지, 전체 45개 ID의 유일성과 누락 없음, 미수집 기록의 원본 링크 유지 확인.
- 독립 코드 검토에서 찾은 재생 닫기/다중 탭/기록 재시도·정렬 경합을 수정하고 회귀 테스트로 검증.
- 라이트/다크, 홈·영상·필터 시트·재생·기록·설정·데스크톱 화면을 캡처하여 검수. 모바일 재생 dialog가 화면 전체 너비를 사용하고 공식 플레이어 영역 최소 200px을 유지함을 확인.
- 공개 출력 검사 통과: API 키·개인 기록·비공개 설정 파일 없음. 기존 시청 기록 저장 키와 schema 1 백업 형식 유지.
- 로컬 Windows 빌드에서 대소문자 인덱스 파일이 덮어써지는 문제도 해결. 경로 bucket만 소문자로 모으고 실제 영상 ID는 구별하며 별도 회귀 테스트 통과.

브라우저 검증은 Chromium의 모바일 에뮬레이션으로 수행했습니다. iPhone/Android 실기기에서의 실제 영상 재생 성공이나 YouTube의 지역·로그인·퍼가기 제한 해제는 보장하지 않습니다. 자동재생이 차단되면 공식 플레이어 버튼을 누르며, 재생 불가 영상은 시간 포함 원본 링크를 사용합니다.

화면 구성과 사용법은 [새 화면 사용법](새화면사용법.md), 레퍼런스와 설계는 [UI 개편 설계](UI-REDESIGN.md)를 확인하세요.
