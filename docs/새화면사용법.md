# 새 화면 사용법

기존 주소 https://mpjfpij.github.io/stellive-watch/ 를 새로고침하면 됩니다. 다시 설치하거나 API 키를 입력할 필요가 없습니다. 기존과 같은 브라우저에서 열면 시청 기록과 수동 분류가 이어집니다.

1. **홈** — 가장 최근 미완료 영상을 큰 썸네일에서 이어봅니다. 기록이 없으면 가장 오래된 일반 후보부터 시작합니다. ‘처음부터 차근차근’은 완료하지 않은 가장 오래된 일반 후보를 엽니다.
2. **영상** — 제목·날짜 검색, 일반 후보/미시청/검토 필요/전체 탭을 이용합니다. 검색창 오른쪽 필터에서 채널·공개 연도·제외됨을 선택합니다. 모든 날짜와 연도는 KST 기준입니다. 목록은 50개씩 교체됩니다.
3. **재생** — 이전·다음은 현재 영상 화면의 검색·분류·채널·연도 조건을 따릅니다. 닫기(←)를 누르면 일시정지하고 위치를 저장합니다. 하단 이어보기 카드를 누르면 같은 재생 화면을 다시 엽니다. 기기에서 자동재생이 막히면 YouTube 플레이어의 재생 버튼을 누릅니다.
4. **분류 수정** — 재생 화면 아래 ‘영상 분류 바꾸기’를 펼쳐 일반 포함/Shorts·VOD 제외/검토/자동 복귀를 선택합니다. 개인 분류는 이 브라우저에 저장됩니다. 검토 필요·제외됨에서도 정상 영상을 확인할 수 있으므로 후보 목록만으로 전체 영상을 판단하지 마세요.
5. **기록** — 최근 이어보기와 완료한 영상을 나누어 봅니다. 현재 수집 목록에서 찾지 못하는 기록도 지우지 않고 YouTube 원본 링크를 제공합니다.
6. **설정** — 시스템/밝게/어둡게 화면 모드, 시청 기록 백업·복원, 채널별 수집 상태를 확인합니다. 공유 분류 내보내기와 기록 삭제는 ‘고급 관리’에 있습니다.

재생 실패·퍼가기 제한 시 재생 화면의 **YouTube 원본에서 보기**를 누르세요. 원본에서 시청한 진행도는 이 사이트로 자동 반영되지 않으므로 완료 버튼을 직접 누르면 됩니다. 기록은 브라우저에만 저장되므로 기기를 바꾸기 전에 설정에서 백업해 주세요.

API 키는 기존 GitHub Actions Secrets에서만 사용합니다. 수집 자동화와 무료 GitHub Pages 운영 방식은 그대로 유지합니다. 새 복제본을 설치하는 방법은 [설치안내](설치안내.md)에 있습니다.
